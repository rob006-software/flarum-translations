# Indonesian inherited translations differences

Translations for Indonesian (`id`) are inherited from Flarum 1.x, but they can be adjusted
independently after inheritance. This page lists all strings which have the same source string on both
sides, but do not match between them: **1** are translated differently and **0** are
translated only in `id`. Altogether they cover **1** components.
